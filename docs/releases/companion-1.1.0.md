**Desktop app (new, optional):** `meterkat-desktop-1.1.0-windows-x64-setup.exe` (per-user install, no admin needed) or `meterkat-desktop-1.1.0-linux-x64.AppImage` is an alternative to the command line. It has a setup wizard and an overview of quota and reset times per provider. It also pairs phones with a QR code, and its settings cover start at sign-in, the update check and the relay. Closing the window collapses it into the tray, and the tray menu shows quota per provider. If a CLI service already syncs the same state directory, the app only displays its data. *Let the app sync instead* hands syncing over to the app. The app checks for new versions; download the new build to update. **Fix (Windows):** the packaged `meterkat.exe` could not start Codex installed with npm ("Codex runtime exited before quota response"). It now runs `codex.js` with `node.exe` from PATH. Without Node on PATH, set `AI_USAGE_CODEX_BIN` to a native `codex.exe`. **Fix:** Claude Code sometimes reports no quota limits for a signed-in account, and setup then blamed sign-in. The companion now asks Claude a second time, and the setup message no longer points to sign-in first.
