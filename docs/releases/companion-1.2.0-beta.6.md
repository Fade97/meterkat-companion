**Beta.** Installations on the Beta channel (1.2.0-beta.5) update to it by themselves; older ones opt in with `meterkat update --prerelease` or download it below. **Desktop island: follows the pinned AI window instantly.** With **Settings → Island sits at → AI window**, the system now reports when the window moves, so the drop keeps up within a few milliseconds while you drag (it used to lag by up to a second). Switching back to an AI window shows the island right away, too. Windows uses WinEvent hooks and Linux (X11) an own X connection; the hooks add no measurable CPU. Everything from [1.2.0-beta.5](companion-1.2.0-beta.5.md) is included.
