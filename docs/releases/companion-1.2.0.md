Everything from the 1.2.0 betas, plus one fix. **Desktop island (new):** while Claude, Codex, ChatGPT or T3 Code is in front, a small Meterkat drop hangs from the top edge of the screen and opens into a short notice when usage jumps and before and after a quota reset. Click it to see every provider at once. Under **Settings → Island sits at** it can hang from the AI window instead and follow it as it moves. It steps aside for full-screen apps and, new since [1.2.0-beta.8](companion-1.2.0-beta.8.md), for tray and context menus on Windows (it used to cover the menu of Claude's tray icon). Turn it off under Settings → *Show the island* or in the tray menu; off on Wayland. **Desktop self-update:** the AppImage (Linux x64) and the Windows installer update themselves with the same signed checks as the CLI; *Install updates automatically* controls it. **Update channel: Stable or Beta** under **Settings → Update channel** or with `meterkat update channel stable|beta`. **Desktop:** *Settings → Coloured bars show* switches between used and remaining, bars use the provider colours from the Android app with glyphs next to the names, and providers never set up on this computer show as one line "Not set up".
