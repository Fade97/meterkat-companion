**Open source.** The companion is now MIT-licensed, and its source code is in this repository. Releases are published here too; 1.0.1 and earlier are in the archived [meterkat-releases](https://github.com/Fade97/meterkat-releases). This is the first release built by the public [release workflow](https://github.com/Fade97/meterkat-companion/blob/main/.github/workflows/release.yml), and every file has a build-provenance attestation. Updates now come from this repository. `meterkat licenses` prints the MIT licence, and the Linux archive contains `LICENSE` instead of `EULA.md`. No functional changes since 1.0.1.
