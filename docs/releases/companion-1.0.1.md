**Fix (data loss):** in 1.0.0, `meterkat delete --help` (and any other extra argument) was ignored, so the command deleted your relay source and local key. In 1.0.1, `--help`, `-h` and `help` only print the usage. `delete` and `rotate-key` accept no argument except `--yes`. Interactively, `delete` asks you to type `delete` and `rotate-key` asks y/N. Without a terminal (scripts) they require `--yes`. Installed 1.0.0 companions update to this release automatically within a day, or right away with `meterkat update`.
