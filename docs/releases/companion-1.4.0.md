# Meterkat companion 1.4.0

The hosted relay has a new address: new registrations use `https://relay.meterkat.fdu.gg` (staging `https://relay-staging.meterkat.fdu.gg`). Existing registrations keep their relay address `meterkat-relay.fabian-duerkop.de`, which is the same relay and stays in service; no re-pairing is needed.

Pair new registrations with Meterkat for Android builds that know the new address. Older app builds refuse pairing links for it until **Advanced: custom relay** allows `https://relay.meterkat.fdu.gg`.
